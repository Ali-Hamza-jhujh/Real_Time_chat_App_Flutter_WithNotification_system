# Real_Time_chat_App_Flutter_WithNotification_system# 🚀 Real-Time Chat App (Flutter) with Notification System

A **real-time chat application** built using **Flutter** with a fully functional **backend system** and **push notification support**. This project allows users to send and receive messages instantly with a smooth and responsive UI.

---

## 📱 Features

- ⚡ Real-time messaging system
- 🔔 Push notification system for new messages
- 👤 User authentication (if included in backend)
- 💬 One-to-one chat support
- 📡 Socket-based real-time communication
- 📱 Cross-platform Flutter app (Android, iOS support)
- 🗂 Clean and modular project structure
